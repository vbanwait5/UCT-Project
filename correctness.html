Correctness &
Query Analysis

We prove the full chain: a query creates coset states, Hadamard interference samples uniformly from s⊥, and O(n) independent rounds determine the unique hidden shift.

Proof chapter35–40 minute readIncludes rank lab

Main theorem

For every Simon oracle with hidden nonzero s∈𝔽2n and every δ∈(0,1), there is a quantum algorithm that outputs s with probability at least 1−δ using

n−1+⌈log2(1/δ)⌉ = O(n+log(1/δ))

oracle queries and polynomial additional computation.

Proof roadmap. We establish four obligations in order: (i) conditioning on an oracle output creates a normalized two-point coset state; (ii) the second Hadamard transform samples exactly and uniformly from s⊥; (iii) random samples span s⊥ with high probability; and (iv) rank–nullity makes s the unique nonzero vector consistent with a full-rank sample matrix.

1. The exact output distribution

Write N=2n. Immediately after the oracle query, the joint state is

|ψ2⟩ = 1/√N ∑x∈𝔽₂ⁿ|x⟩|f(x)⟩.

Choose one representative r from each two-element coset {r,r⊕s}. Grouping equal output values rewrites the same state as

|ψ2⟩ = 1/√N ∑cosets r+H(|r⟩+|r⊕s⟩)|f(r)⟩.

Lemma 1 (Post-measurement coset state)

If the second register is measured as f(x0), then that outcome has probability 2/N and the normalized state of the first register is

|Cx₀⟩ = (|x0⟩+|x0⊕s⟩)/√2.

Proof. The projector onto second-register outcome |f(x0)⟩ keeps exactly two terms, because the promise says f(x)=f(x0) iff x∈{x0,x0⊕s}. The unnormalized first-register vector is

1/√N (|x0⟩+|x0⊕s⟩).

The basis vectors are orthogonal, so its squared norm is 1/N+1/N=2/N. Dividing by √(2/N) gives the claimed normalized state. ∎

Lemma 2 (Fourier sampling a Simon coset)

For any x0 and nonzero s, applying H⊗n to |Cx₀⟩ and measuring yields a uniformly random z∈s⊥.

Proof. Use the Hadamard identity

H⊗n|x⟩ = 1/√N ∑z∈𝔽₂ⁿ(−1)x·z|z⟩.

Applying it to both terms of the coset state and using linearity gives

H⊗n|Cx₀⟩ = 1/√(2N) ∑z[(−1)x₀·z+(−1)(x₀⊕s)·z]|z⟩.

Because the dot product is over 𝔽2, (x0⊕s)·z = x0·z + s·z mod 2. Hence

(−1)(x₀⊕s)·z=(−1)x₀·z(−1)s·z,

so the amplitude of |z⟩ factors as

αz = (−1)x₀·z[1+(−1)s·z] / √(2N).

There are two cases:

  • If s·z=1, then [1+(−1)] = 0, so destructive interference makes αz=0.
  • If s·z=0, then [1+1] = 2, so |αz|² = 4/(2N)=2/N=1/2n−1.

Finally, the map Ls(z)=s·z is a nonzero linear functional because s≠0. Its rank is one, so rank–nullity gives dim(ker Ls)=n−1. Therefore |s⊥|=2n−1. Exactly those vectors occur, each with probability 1/2n−1. ∎

Corollary 3 (The output-register measurement is unnecessary)

Discarding the second register produces an equal mixture of the coset states |Cr⟩. Lemma 2 gives the same uniform distribution on s⊥ for every r, so averaging over r leaves that distribution unchanged.

2. When do the equations determine s?

Every sampling round starts with fresh registers, applies the same circuit, and is measured separately. Thus the rows z1,z2,… are independent and identically distributed. By Lemma 2, each is uniform on the d-dimensional vector space s⊥, where d=n−1.

Lemma 4 (Rank determines the candidate set)

Let Z be the matrix whose rows are the sampled vectors. If rank(Z)=r, then the solution space {v∈𝔽2n: Zv=0} has dimension n−r and contains the true secret s. In particular, if rank(Z)=n−1, its only solutions are 0 and s.

Proof. Every sampled row z satisfies z·s=0, hence Zs=0. Rank–nullity gives dim(ker Z)=n−rank(Z)=n−r. When r=n−1, ker Z is one-dimensional. Since s is a nonzero member, ker Z=span{s}={0,s}. ∎

Proposition 5 (Full rank from exactly d samples)

The probability that d independent uniform samples from a d-dimensional vector space are linearly independent is

∏r=0d−1(1−2r−d) = ∏j=1d(1−2−j).

Proof. Condition on the first r rows being independent. Their span then contains exactly 2r of the 2d possible next rows. The next sample increases rank with conditional probability 1−2r−d. Multiply these conditional probabilities for r=0,1,…,d−1. Reindexing with j=d−r yields the second product. ∎

The product decreases to approximately 0.288 as d grows. So n−1 samples already succeed with a constant probability bounded away from zero, but extra samples give a cleaner high-probability guarantee.

3. A high-probability bound

Theorem 6 (Rank accumulation)

Let z1,…,zt be independent uniform samples from s⊥. Then

Pr[span{z1,…,zt} ≠ s⊥] < 2(n−1)−t.

Proof. Set d=n−1 and choose a linear isomorphism φ:s⊥→𝔽2d. The images yi=φ(zi) are independent uniform vectors in 𝔽2d, and they span 𝔽2d exactly when the original zi span s⊥.

If the yi fail to span the whole space, their span W is a proper subspace. The orthogonal complement W⊥ under the standard coordinate dot product has dimension at least one, so it contains some nonzero w. Therefore w·yi=0 for every i.

For a fixed nonzero w, the linear functional y↦w·y is nonzero, so exactly half of 𝔽2d lies in its kernel. Hence

Pr[w·y1=⋯=w·yt=0] = 2−t.

There are 2d−1 possible nonzero w. A union bound gives

Pr[failure] ≤ (2d−1)2−t < 2d−t = 2(n−1)−t.  ∎

Taking t=n−1+c makes failure probability less than 2−c. Equivalently, t=n−1+⌈log2(1/δ)⌉ samples suffice for failure probability at most δ.

Theorem 7 (End-to-end correctness)

On every oracle satisfying Simon’s promise, the algorithm that takes t=n−1+c samples, returns the unique nonzero nullspace vector when rank is n−1, and otherwise reports failure:

  1. never returns an incorrect secret;
  2. returns the true secret with probability greater than 1−2−c;
  3. uses exactly t oracle queries.

Proof. Lemma 2 ensures every row is orthogonal to s, so s always lies in ker Z. If rank(Z)=n−1, Lemma 4 says ker Z={0,s}, hence the returned nonzero vector is exactly s. Theorem 6 bounds the probability that rank remains below n−1. Each round contains one oracle call. ∎

Connection: amplification in probabilistic time

As with BPP error reduction, independent repetition converts constant success into exponentially small failure. Here the aggregation rule is not majority vote: it is rank growth in a vector space.

4. Query, time, and space accounting

Known quantum gatesO(n²) plus oracle costO(n) Hadamards per round across O(n) rounds
Qubits2n plus oracle workspaceTwo n-qubit registers, reusable each round
Classical postprocessingO(n³) bit operationsGaussian elimination on an O(n) × n matrix
Classical storageO(n²) bitsStore O(n) sampled n-bit rows

The bounded-error version fixes t=n−1+⌈log2(1/δ)⌉ rounds in advance. A useful alternative is to keep sampling until the matrix reaches rank n−1. Because rank is observable from the classical rows, this stopping rule never mistakes failure for success.

Proposition 8 (Expected queries for the zero-error version)

The expected number of samples required to reach rank d=n−1 is less than d+2=n+1.

Proof. At rank r, a new sample increases rank with probability 1−2r−d. The expected waiting time for that increase is the reciprocal. Therefore

E[T] = ∑r=0d−1 1/(1−2r−d) = d + ∑k=1d 1/(2k−1) < d+2.

The last inequality follows from 1 + 1/3 + 1/7 + 1/15 + ··· < 2. Thus Simon sampling can be viewed either as a bounded-error O(n)-query algorithm with a fixed budget or as a zero-error expected-O(n)-query algorithm with a random stopping time.

The query complexity is linear, but the full idealized algorithm also includes polynomial classical work. This distinction is central: an exponential query separation is stronger than an algorithmic anecdote, but weaker than a hardware runtime benchmark.

6. Proof subtleties worth noticing

  • Zero is a valid sample. It gives the tautology 0·s=0 and adds no rank.
  • Samples are uniform only under the exact promise. Noise or extra collisions change the state and its Fourier spectrum.
  • Rank n−1 is the stopping condition. Rank n is impossible because every row lies in s⊥.
  • Full rank already certifies correctness. Under the promise, no extra oracle query is required once rank is n−1. If one tries a candidate earlier, two queries can test whether f(0)=f(s′).
  • Conditioning is legitimate. We condition on a second-register outcome only to analyze the first register. Corollary 3 shows that omitting that measurement gives the same final z distribution.
  • Uniformity is stronger than orthogonality. Showing z·s=0 proves support; the equal squared amplitudes prove that no valid equation is favored.

Proof architecture

Promise gives two-element cosets. Measurement isolates a normalized coset state. Hadamard interference makes its Fourier support exactly s⊥. Random linear algebra spans s⊥ after O(n) rounds. Rank–nullity leaves span{s} as the only possible nullspace.
