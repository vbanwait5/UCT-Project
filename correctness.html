Chapter 06

Why the Algorithm
Works

The proof has two main ideas: interference guarantees that every measured equation is correct, and ordinary binary linear algebra shows that enough independent equations determine the secret.

25–30 minute read

Main theorem

For every Simon oracle with hidden nonzero s∈𝔽2n and every δ∈(0,1), there is a quantum algorithm that outputs s with probability at least 1−δ using

n−1+⌈log2(1/δ)⌉ = O(n+log(1/δ))

oracle queries and polynomial additional computation.

Proof roadmap. We will first compute the amplitude of every possible measurement z and see that it is zero unless z·s=0. We will then collect these valid equations into a matrix and show that O(n) random rows determine the one nonzero vector s in its nullspace.

1. Why every sampled equation is valid

We begin at the point where the oracle has been queried. Writing N=2n, the joint state of the two registers is

|ψ2⟩ = 1/√N ∑x∈𝔽₂ⁿ|x⟩|f(x)⟩.

The promise tells us how to reorganize this sum. Choose one representative r from each two-element coset {r,r⊕s}; grouping the two terms that share an output label gives the equivalent expression

|ψ2⟩ = 1/√N ∑cosets r+H(|r⟩+|r⊕s⟩)|f(r)⟩.

Lemma 1 (Post-measurement coset state)

If the second register is measured as f(x0), then that outcome has probability 2/N and the normalized state of the first register is

|Cx₀⟩ = (|x0⟩+|x0⊕s⟩)/√2.

Proof. Measuring f(x0) keeps exactly the two terms whose inputs are x0 and x0⊕s. Before normalization, the first register is

1/√N (|x0⟩+|x0⊕s⟩).

The basis vectors are orthogonal, so its squared norm is 1/N+1/N=2/N. Dividing by √(2/N) gives the claimed normalized state. ∎

Lemma 2 (Fourier sampling a Simon coset)

For any x0 and nonzero s, applying H⊗n to |Cx₀⟩ and measuring yields a uniformly random z∈s⊥.

Proof. Use the Hadamard identity

H⊗n|x⟩ = 1/√N ∑z∈𝔽₂ⁿ(−1)x·z|z⟩.

Applying it to both terms of the coset state and using linearity gives

H⊗n|Cx₀⟩ = 1/√(2N) ∑z[(−1)x₀·z+(−1)(x₀⊕s)·z]|z⟩.

Because the dot product is over 𝔽2, (x0⊕s)·z = x0·z + s·z mod 2. Hence

(−1)(x₀⊕s)·z=(−1)x₀·z(−1)s·z,

so the amplitude of |z⟩ factors as

αz = (−1)x₀·z[1+(−1)s·z] / √(2N).

The factor in brackets now separates the analysis into two exhaustive cases:

  • If s·z=1, then [1+(−1)] = 0, so destructive interference makes αz=0.
  • If s·z=0, then [1+1] = 2, so |αz|² = 4/(2N)=2/N=1/2n−1.

Exactly half of all strings satisfy s·z=0. To see this, choose a coordinate where s has a 1; flipping that bit of z toggles the dot product and pairs every valid string with one invalid string. Thus there are 2n−1 surviving outcomes, each with probability 1/2n−1. The distribution is uniform on s⊥. ∎

2. When do the equations determine s?

The quantum part of the proof is now complete: we know the exact distribution of one sample. What remains is a question in random linear algebra. Each round begins with fresh registers and is measured separately, so the rows z1,z2,… are independent and identically distributed. By Lemma 2, they are uniform on the d-dimensional space s⊥, where d=n−1.

Lemma 3 (Rank determines the candidate set)

Let Z be the matrix whose rows are the sampled vectors. If rank(Z)=r, then the solution space {v∈𝔽2n: Zv=0} has dimension n−r and contains the true secret s. In particular, if rank(Z)=n−1, its only solutions are 0 and s.

Proof. Every sampled row z satisfies z·s=0, hence Zs=0. Rank–nullity gives dim(ker Z)=n−rank(Z)=n−r. When r=n−1, ker Z is one-dimensional. Since s is a nonzero member, ker Z=span{s}={0,s}. ∎

A dependent row is still a correct equation, but it does not reduce the candidate set. The only possible failure is therefore collecting too many redundant rows. The next section bounds that probability.

3. Why O(n) samples are enough

Theorem 4 (Rank accumulation)

Let z1,…,zt be independent uniform samples from s⊥. Then

Pr[span{z1,…,zt} ≠ s⊥] < 2(n−1)−t.
Proof of the probability bound

Write d=n−1 and represent s⊥ using d binary coordinates. If the samples fail to span the whole space, there is some nonzero test vector w orthogonal to every sampled row. For one fixed w, a uniform row has dot product zero with probability 1/2, so all t rows pass that test with probability 2−t. There are 2d−1 possible nonzero w. The union bound therefore gives failure probability at most (2d−1)2−t<2d−t. Substituting d=n−1 proves the theorem.

Substituting t=n−1+c leaves failure probability below 2−c. Equivalently, choosing t=n−1+⌈log2(1/δ)⌉ makes the failure probability at most δ. This is the quantitative step that turns the sampling procedure into a bounded-error algorithm.

Theorem 5 (End-to-end correctness)

On every oracle satisfying Simon’s promise, the algorithm that takes t=n−1+c samples, returns the unique nonzero nullspace vector when rank is n−1, and otherwise reports failure:

  1. never returns an incorrect secret;
  2. returns the true secret with probability greater than 1−2−c;
  3. uses exactly t oracle queries.

Proof. Lemma 2 ensures every row is orthogonal to s, so s always lies in ker Z. If rank(Z)=n−1, Lemma 3 says ker Z={0,s}, hence the returned nonzero vector is exactly s. Theorem 4 bounds the probability that rank remains below n−1. Each round contains one oracle call. ∎

4. Final accounting

ResourceBoundReason
Oracle queriesO(n + log(1/δ))One per sampled equation
Known quantum gatesO(n²) plus oracle costO(n) Hadamards per round across O(n) rounds
Classical postprocessingO(n³) bit operationsGaussian elimination on an O(n) × n matrix

We can therefore state the result at the appropriate level of strength. The query complexity is linear and every additional operation is polynomial in the ideal circuit model. This is a genuine complexity-theoretic separation in oracle access, but it is not by itself a claim about wall-clock performance on physical hardware.

5. Common questions about the proof

  • Zero is a valid sample. It gives the tautology 0·s=0 and adds no rank.
  • Samples are uniform only under the exact promise. Noise or extra collisions change the state and its Fourier spectrum.
  • Rank n−1 is the stopping condition. Rank n is impossible because every row lies in s⊥.
  • Full rank already certifies correctness. Under the promise, no extra oracle query is required once rank is n−1. If one tries a candidate earlier, two queries can test whether f(0)=f(s′).
  • Conditioning is legitimate. We condition on a second-register outcome only to analyze the first register. Corollary 3 shows that omitting that measurement gives the same final z distribution.
  • Uniformity is stronger than orthogonality. Showing z·s=0 proves support; the equal squared amplitudes prove that no valid equation is favored.
