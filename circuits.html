& Oracles

We now need only one bridge from states to algorithms: how a circuit calls a classical function without losing reversibility.

Circuit model12–15 minute readIncludes oracle lab

1. From a unitary to a circuit

A quantum algorithm is a sequence of small gates connected by qubit wires. Each gate acts on only one or two qubits, so a polynomial-size circuit has a polynomial-length description. This prevents us from hiding an exponentially complicated transformation inside one “free” instruction.

Definition 1 (Quantum circuit family)

A quantum circuit is a sequence of constant-size unitary gates. A family {Cn} is efficient when it uses poly(n) gates and a classical polynomial-time algorithm can produce Cn from 1n.

The second condition is called uniformity. It simply says that the circuits for different input lengths come from one algorithm rather than from unrelated advice.

|0ⁿ⟩IUf

This skeleton separates the algorithm’s known gates from the single black-box operation Uf. Query complexity counts occurrences of that oracle box; ordinary circuit complexity counts all gates after the oracle itself has been assigned an implementation.

2. Why classical functions need reversible embeddings

The next issue is access to the function f. Because unitary evolution is injective, the seemingly natural map |x⟩ ↦ |f(x)⟩ is invalid whenever f has a collision: two orthogonal basis states would be sent to the same vector, so inner products would not be preserved. We therefore keep the input and write the answer into a separate target register.

Key construction (A reversible oracle)

For every f : {0,1}n → {0,1}m, the map Uf|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩ is unitary.

Why it is reversible. The input x is preserved, and applying the map twice restores y because a ⊕ a = 0. Thus Uf−1 = Uf.

3. Coherent access is more than parallel evaluation

Linearity determines the oracle’s action on superpositions:

Uf ∑x,y αx,y|x⟩|y⟩ = ∑x,y αx,y|x⟩|y ⊕ f(x)⟩.

This equation is sometimes summarized by saying that the oracle “evaluates every input at once.” The phrase is suggestive but incomplete, because the resulting state is not a readable truth table: measurement still returns only one classical outcome. The genuine opportunity is subtler. Later gates can bring contributions from different inputs to the same basis state, allowing a global property of f to determine whether their amplitudes reinforce or cancel.

Why the exact oracle rule matters

Different quantum encodings of a classical black box need not be equivalent at unit cost. Query-complexity claims must state the oracle action. Simon’s algorithm uses the standard XOR oracle above.

These measures answer different questions, and they should not be conflated. A query upper bound becomes a runtime upper bound only after the oracle has been implemented by a circuit and all remaining quantum and classical work has been counted. Simon’s separation deliberately isolates black-box information access; later chapters will state that boundary explicitly whenever the result is interpreted.
