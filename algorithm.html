Chapter 05

Simon’s Algorithm

One coherent query produces no readable list of values. Instead, a Hadamard transform converts the oracle’s hidden XOR symmetry into a uniformly random linear constraint.

Quantum algorithm25–30 minute readIncludes state stepper

1. The algorithm at one level of abstraction

Assume oracle access to a Simon function with hidden nonzero s ∈ 𝔽2n. A single sampling round is:

  1. Initialize two n-qubit registers to |0n⟩|0n⟩.
  2. Apply H⊗n to the first register.
  3. Apply the oracle Uf.
  4. Ignore or measure the second register.
  5. Apply H⊗n to the first register and measure it, obtaining z.

The invariant is that every returned z satisfies z · s = 0 over 𝔽2. Repeating the round produces a homogeneous linear system whose one-dimensional nullspace is span{s}.

Algorithm 1 (Simon sampling)

repeat until the sampled equations have rank n−1: run the quantum sampling round and append the measured row z. Then compute the unique nonzero vector in the nullspace over 𝔽2.

2. Prepare and query

The initial state is |0n⟩|0n⟩. Applying a Hadamard to every qubit of the first register gives

|ψ1⟩ = 1/√(2n) ∑x∈𝔽₂ⁿ |x⟩|0n⟩.

The oracle then acts once:

|ψ2⟩ = 1/√(2n) ∑x∈𝔽₂ⁿ |x⟩|f(x)⟩.

This state correlates every input with its output. Because f(x) = f(x ⊕ s), each output label is attached to exactly two first-register basis states.

Important (Superposition is not the conclusion)

At this point, measuring both registers would reveal one ordinary pair (x, f(x)) and waste the structure. The useful step is to erase which-pair information while preserving coherence between the two members of a fiber.

3. Isolating a coset state

Suppose the second register is measured and the outcome is f(x0). Exactly two terms are consistent with this result. The first register becomes

|Cx₀⟩ = (|x0⟩ + |x0 ⊕ s⟩)/√2.

This is the uniform superposition over the coset x0 + H. The representative x0 is random. Crucially, the relative displacement s is the same in every possible coset.

Deep insight (The output measurement is optional)

We may discard the second register without measuring it. The first register is then a classical mixture of coset states, and every coset yields the same final distribution on z. Measuring the output is a proof device, not a required source of computational power.

4. Interference exposes orthogonality

Apply H⊗n to the coset state. Using H⊗n|x⟩ = 2−n/2∑z(−1)x·z|z⟩, we obtain

1/√(2n+1) ∑z (−1)x₀·z[1 + (−1)s·z]|z⟩.

If s · z = 1, the bracket is 1 − 1 = 0: the amplitude cancels. If s · z = 0, the bracket is 2: the paths reinforce. Therefore only vectors in the orthogonal subspace

s⊥ = {z ∈ 𝔽2n : z · s = 0}

can be measured. The phase (−1)x0·z depends on the random coset representative, but its squared magnitude is one, so it does not affect the measurement distribution.

5. Repeat and solve over 𝔽₂

Each run outputs a uniformly random row z in the (n−1)-dimensional subspace s⊥. Stack the samples into a matrix Z. We seek a nonzero solution to

Zs = 0   over 𝔽2.

Once rank(Z) = n−1, its nullspace has dimension one. Since the true s lies in the nullspace, the only nonzero solution is s. Gaussian elimination uses XOR in place of subtraction.

Connection: randomized computation

The quantum circuit is randomized only at measurement. Correctness is one-sided at the equation level: a sampled row never violates z · s = 0. Failure occurs because the rows may be linearly dependent, and repetition reduces that failure probability exponentially.

Takeaway

The oracle creates a two-point periodic state; the Hadamard transform maps translation symmetry in the primal space to orthogonality constraints in the dual space. The algorithm learns s indirectly by sampling s⊥.
