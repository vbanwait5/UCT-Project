Chapter 07

Classical Randomized
Lower Bound

We formalize the transcript argument: without a collision, the posterior distribution on the hidden shift remains nearly uniform, forcing the birthday scale 2n/2.

Lower-bound proof35–40 minute readIncludes collision simulator

1. What must be proved?

An O(n)-query quantum algorithm alone does not establish a speedup. We need a lower bound against every classical randomized algorithm, including adaptive algorithms whose next query depends on all previous answers.

Theorem 1 (Classical randomized query complexity)

Every randomized classical algorithm that solves Simon’s search problem with success probability at least 2/3 on every promised oracle makes Ω(2n/2) queries in the worst case. Moreover, O(2n/2) queries suffice. Hence

R1/3(Simonn) = Θ(2n/2).

The lower bound has two ideas: choose a symmetric distribution over hard inputs, then show that a deterministic algorithm using too few queries has low average success under that distribution.

2. A hard input distribution

Let N=2n and M=N−1. Define a distribution μ over promised Simon oracles in two stages:

  1. Choose s uniformly from the M nonzero strings.
  2. The pairs {x,x⊕s} are the N/2 cosets of {0,s}. Assign distinct output labels to these pairs by a uniformly random injection into {0,1}n.

Now fix an arbitrary deterministic adaptive algorithm A making at most q queries. We may assume its queries are distinct, because repeating an input returns an already-known answer and cannot improve the transcript.

Definition 2 (Classical transcript)

After t queries, the transcript is Tt=((x1,f(x1)),…, (xt,f(xt))). It is collision-free if all observed output labels are distinct.

On a collision-free path, every oracle response is a fresh random label. The actual bit pattern of that label is independent of s; only equality between labels can expose a pair.

Remark (The oracle labels are camouflage)

The lower bound randomizes labels to prevent the algorithm from exploiting their representation. The only invariant information is whether two answers are equal.

3. The collision probability lemma

For a set Q={x1,…,xq} of queried inputs, define its nonzero difference set

D(Q) = {xi⊕xj : 1≤i<j≤q}.

There are at most C=q(q−1)/2 elements in D(Q). A collision appears exactly when s∈D(Q).

Lemma 3 (Posterior after a collision-free transcript)

Conditioned on a particular collision-free transcript with query set Q, the secret s is uniform over the set

S(Q)=({0,1}n ∖ {0}) ∖ D(Q).

Consequently, any deterministic guess succeeds with conditional probability at most 1/(M−|D(Q)|) ≤ 1/(M−C).

Proof. A candidate s is inconsistent with the transcript exactly when some queried pair differs by s, because that pair should have received equal labels. Thus the consistent secrets are precisely S(Q). For every s∈S(Q), all q queried points lie in distinct s-cosets. The number of injective assignments of the observed q distinct labels to those cosets is the same for every such s. Since the prior on s was uniform, Bayes’ rule leaves a uniform posterior on S(Q). ∎

Lemma 4 (Collision bound for adaptive algorithms)

For every deterministic adaptive q-query algorithm under μ,

Pr[the transcript contains a collision] ≤ C/M = q(q−1)/[2(N−1)].

Proof. Use deferred decisions. Imagine first supplying A with q distinct fresh labels, which determines the entire collision-free query path Q because A is deterministic. Those labels are independent of s. The real interaction follows this path until a collision, and such a collision occurs only if s equals one of the at most C differences in D(Q). A uniform nonzero s lands in that set with probability at most C/M. ∎

Proposition 5 (Average success bound)

Assume C=q(q−1)/2<M. Every deterministic adaptive q-query algorithm has success probability under μ at most

C/M + 1/(M−C).

Proof. Split on whether a collision occurs. The success contribution of collision transcripts is at most their total probability, bounded by C/M in Lemma 4. On a collision-free transcript, Lemma 3 bounds the best possible guess by 1/(M−C). Adding the two contributions proves the claim. ∎

For example, if q≤√M/4, then C≤M/32. For n≥3, the displayed success bound is strictly below 2/3. Therefore constant success requires q=Ω(√M)=Ω(2n/2).

4. From deterministic average-case to randomized worst-case

Yao’s minimax principle (query form)

To lower-bound the worst-case cost of bounded-error randomized algorithms, it suffices to exhibit a distribution μ over inputs such that every deterministic algorithm with smaller cost has error greater than 1/3 on an input drawn from μ.

Application. Suppose for contradiction that a randomized q-query algorithm R succeeds with probability at least 2/3 on every promised oracle, where q=o(2n/2). Average first over f∼μ and then over R’s random coins. The resulting average success is still at least 2/3.

Fixing R’s coins turns it into a deterministic q-query algorithm. Since the average over coin fixings is at least 2/3, at least one fixing must have average success at least 2/3 on μ. Proposition 5 says every such deterministic algorithm has success below 2/3 for q=o(2n/2), a contradiction. Therefore R1/3(Simonn)=Ω(2n/2).

Connection: probabilistic time complexity

This is the same quantifier discipline used for BPP: one randomized machine must have bounded error on every input. Choosing a random input distribution is a proof technique for a lower bound; it does not weaken the final worst-case guarantee.

5. The matching birthday upper bound

A classical randomized algorithm samples q distinct inputs uniformly, stores their output labels, and stops when two outputs match. A collision yields s immediately by XORing the corresponding inputs.

For a fixed secret, the domain is a perfect matching of N points. If i collision-free inputs have already been selected, then i of the N−i remaining points are their forbidden partners. Thus the probability that the next point avoids a collision is (N−2i)/(N−i). Multiplying gives

Pr[no collision] = ∏i=0q−1(N−2i)/(N−i)

which is equivalently

Pr[no collision] = [2q · C(N/2,q)] / C(N,q),   q ≤ N/2.

Using 1−u≤e−u,

Pr[no collision] ≤ exp(−∑i=0q−1 i/(N−i)) ≤ exp(−q(q−1)/(2N)).

Choosing q≥1+√(2N ln 3) makes this probability at most 1/3, so one run finds a collision and recovers s with probability at least 2/3. Therefore R1/3(Simonn)=O(√N)=O(2n/2), matching the lower bound.

Conclusion

The classical proof is tight: Θ(2n/2) queries are both necessary and sufficient. Together with the O(n)-query quantum algorithm, this establishes the exponential separation.

7. Connections to other lower-bound methods

Communication complexity

Both models reason from a restricted transcript. In communication complexity the scarce resource is exchanged bits; here it is oracle answers. Rectangle arguments do not directly prove this query bound, but the information-bottleneck viewpoint is shared.

Time hierarchy

A hierarchy theorem separates two time bounds within one machine model. Simon separates two access models on one promise problem. Both require an upper bound and an adversarial lower bound, but the conclusions are logically different.

Randomized algorithms

Repeated sampling, birthday phenomena, and error reduction are classical tools. The surprise is not that quantum measurement is random; it is that each quantum sample comes from s⊥ rather than from isolated function values.

Adversary thinking

Before a collision, an adversary can keep many hidden shifts consistent with the transcript. This “maintain indistinguishable worlds” pattern recurs throughout complexity lower bounds.
