Chapter 07

Classical Randomized
Lower Bound

Until a classical transcript contains a collision, the hidden shift is almost perfectly concealed. The birthday scale 2n/2 is therefore unavoidable.

Lower bound25–30 minute readIncludes collision simulator

1. What must be proved?

An O(n)-query quantum algorithm alone does not establish a speedup. We need a lower bound against every classical randomized algorithm, including adaptive algorithms whose next query depends on all previous answers.

Theorem 1 (Classical randomized query complexity)

Every randomized classical algorithm that solves Simon’s search problem with success probability at least 2/3 on every promised oracle makes Ω(2n/2) queries in the worst case. Moreover, O(2n/2) queries suffice. Hence

R1/3(Simonn) = Θ(2n/2).

The lower bound has two ideas: choose a symmetric distribution over hard inputs, then show that a deterministic algorithm using too few queries has low average success under that distribution.

2. A hard input distribution

Let N = 2n. Choose the secret s uniformly from the N−1 nonzero strings. This partitions the domain into N/2 pairs {x, x ⊕ s}. Assign distinct random output labels to these pairs.

Consider a fixed deterministic adaptive algorithm. Before it sees a repeated output, every response is a fresh random label. Those fresh labels reveal no preference among the secrets not already ruled out by pairwise differences of queried points. Adaptivity cannot manufacture information from the names of fresh labels.

Remark 2 (The oracle labels are camouflage)

The lower bound randomizes labels to prevent the algorithm from exploiting their representation. The only invariant information is whether two answers are equal.

3. The collision probability lemma

Suppose the algorithm has queried distinct points x1,…,xq. A collision occurs exactly when

s = xi ⊕ xj   for some i ≠ j.

There are at most (q choose 2) such nonzero pairwise differences. Since s was uniform among N−1 possibilities, a union bound gives

Pr[collision in q queries] ≤ q(q−1) / [2(N−1)].

If q = o(√N), this probability is o(1). Conditioned on no collision, the algorithm can only guess among almost all remaining secrets; its success probability is also negligible. Constant success therefore requires q = Ω(√N) = Ω(2n/2).

Why adaptivity does not break the bound

Until the first collision, the answers are independent fresh labels. Conditioning on that collision-free transcript may determine future queries, but it does not correlate those queries with the still-unseen random secret beyond ruling out differences already tested. The same pair-counting argument applies.

4. From deterministic average-case to randomized worst-case

Yao’s minimax principle (query form)

To lower-bound the worst-case cost of bounded-error randomized algorithms, it suffices to exhibit a distribution μ over inputs such that every deterministic algorithm with smaller cost has error greater than 1/3 on an input drawn from μ.

Our random-secret, random-label distribution is μ. The collision calculation shows that any deterministic q-query algorithm with q = o(2n/2) has average success far below 2/3. Yao’s principle then gives the same asymptotic lower bound for worst-case randomized query complexity.

Connection: probabilistic time complexity

This is the same quantifier discipline used for BPP: one randomized machine must have bounded error on every input. Choosing a random input distribution is a proof technique for a lower bound; it does not weaken the final worst-case guarantee.

5. The matching birthday upper bound

A classical randomized algorithm samples q distinct inputs uniformly, stores their output labels, and stops when two outputs match. A collision yields s immediately by XORing the corresponding inputs.

For a fixed secret, the domain is a perfect matching of N points. The probability that a uniformly random q-subset contains no complete matched pair is

Pr[no collision] = [2q · C(N/2,q)] / C(N,q),   q ≤ N/2.

When q = Θ(√N), collision probability is bounded below by a positive constant. Repeating a constant number of times reaches success at least 2/3. This matches the lower bound.

7. Connections to other lower-bound methods

Communication complexity

Both models reason from a restricted transcript. In communication complexity the scarce resource is exchanged bits; here it is oracle answers. Rectangle arguments do not directly prove this query bound, but the information-bottleneck viewpoint is shared.

Time hierarchy

A hierarchy theorem separates two time bounds within one machine model. Simon separates two access models on one promise problem. Both require an upper bound and an adversarial lower bound, but the conclusions are logically different.

Randomized algorithms

Repeated sampling, birthday phenomena, and error reduction are classical tools. The surprise is not that quantum measurement is random; it is that each quantum sample comes from s⊥ rather than from isolated function values.

Adversary thinking

Before a collision, an adversary can keep many hidden shifts consistent with the transcript. This “maintain indistinguishable worlds” pattern recurs throughout complexity lower bounds.
